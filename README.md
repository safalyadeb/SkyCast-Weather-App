# 🌤️ SkyCast — Weather Forecasting Web App

**Weather made beautiful.**

SkyCast is a modern, responsive weather forecasting web application designed to make checking the weather simple, informative, and visually engaging.

It provides real-time weather information, a dynamic day-and-night sky experience, sunrise and sunset tracking, and a 7-day weather forecast through a clean glassmorphism-inspired interface.

## ✨ Features

- 🌍 **City Search:** Search for weather conditions in cities around the world.
- 📍 **Current Location:** Get weather information based on your geographical location.
- 🌡️ **Live Weather:** View current temperature and feels-like temperature.
- 💧 **Weather Details:** Check humidity, wind speed, atmospheric pressure, and visibility.
- 🌅 **Sunrise & Sunset:** View sunrise and sunset times with a daylight progress tracker.
- ☀️ **Dynamic Sun & Moon:** Animated sun and moon positioning based on local time.
- 🌌 **Day & Night Experience:** Dynamic sky theme with stars and celestial elements.
- 📅 **7-Day Forecast:** Explore upcoming weather conditions.
- 🌡️ **Temperature Toggle:** Switch between Celsius (°C) and Fahrenheit (°F).
- 📱 **Responsive Design:** Designed for desktop, tablet, and mobile screens.

## 🚀 Getting Started

Follow these steps to run SkyCast locally.

**1. Clone the repository**

```bash
git clone https://github.com/safalyadeb/SkyCast-Weather-App.git
```

**2. Navigate to the project folder**

```bash
cd SkyCast-Weather-App
```

**3. Open the project**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No backend setup or API key is required for the current Open-Meteo integration.

## 🌐 API & Data Source

SkyCast uses the free [Open-Meteo API](https://open-meteo.com/) for:

- Current weather conditions
- Daily weather forecasts
- Sunrise and sunset information
- City geocoding and location search
